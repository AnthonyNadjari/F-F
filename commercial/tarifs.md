# Grille tarifaire

Document interne. Il sert à chiffrer vite et à dire non sans hésiter ; il n'est
pas destiné au client, qui reçoit un devis.

## Les formules

| | **Essentiel** | **Cabinet** |
|---|---|---|
| **Prix** | 350 € | 500 € |
| Pages | Une page, sections ancrées | Jusqu'à 5 pages |
| Design | Personnalisé à partir du brief | Personnalisé, direction plus poussée |
| Responsive | Oui | Oui |
| Formulaire de contact | Oui | Oui |
| Mentions légales et confidentialité | Oui | Oui |
| Référencement de base | Titres, descriptions, données structurées | Idem + page par spécialité |
| Corrections incluses | 2 séries | 2 séries |
| Délai | 3 jours ouvrés | 5 jours ouvrés |

| Page supplémentaire | 70 € | |

## Ce qui n'est jamais inclus

- Le nom de domaine (10 à 15 €/an, acheté par le client, à son nom)
- L'hébergement, si le client veut le sien
- La création d'un logo
- Le référencement payant, les campagnes, les réseaux sociaux
- La reprise d'un site existant sur une autre technologie

## Comment chiffrer

Partir de **Essentiel**. Passer à **Cabinet** dès qu'un de ces signaux apparaît :
plusieurs praticiens à présenter, plusieurs spécialités qui méritent chacune sa
page, ou un contenu déjà rédigé et volumineux.

Une remise se justifie sur le volume (deux sites pour le même cabinet), jamais
sur la négociation. Un client qui négocie 50 € sur un site à 350 € négociera
aussi chaque correction.

## Note sur la marge

À 350 € pour trois jours, la journée est à environ 115 €. C'est un prix de
lancement, acceptable pour construire le portfolio, pas un modèle durable.

Deux leviers, dans cet ordre : la **maintenance** (25 €/mois × 20 clients =
500 €/mois de récurrent, pour quelques heures de travail), et le **temps de
production** (la bibliothèque de composants, qui doit faire passer un site de
trois jours à un jour).

Tant que le second levier n'existe pas, tenir les délais annoncés compte plus
que le prix affiché : un site livré en retard coûte la recommandation, qui est
le seul canal d'acquisition gratuit sur ce marché.
